# 科电软件推荐之 Obsidian

这里分享一份 Obsidian 入门配置，包含基础外观、附件保存方式，以及三个插件的个人设置。

## 获取配置

点击 [下载配置压缩包](https://github.com/kedian-club/kedian-software-obsidian/archive/refs/heads/main.zip)，下载完成后解压，打开解压出来的文件夹，就能看到 `.obsidian` 配置文件夹。

也可以在仓库页面点击 **Code → Download ZIP**。在 Windows 文件管理器中，如看不到配置文件夹，请开启“显示隐藏的项目”。

## 使用配置

建议先在新建的空知识库中体验：

1. 在 Obsidian 中创建一个新知识库，然后关闭 Obsidian。
2. 将下载的 `.obsidian` 文件夹复制到知识库根目录。如果已有同名文件，请按需要合并并替换。
3. 重新打开 Obsidian，在“设置 → 第三方插件”中搜索、安装并启用 **Calendar**、**Dynamic Outline** 和 **Editing Toolbar**。
4. 如果安装插件后对应设置没有生效，关闭 Obsidian，再把下载包中对应插件目录里的 `data.json` 复制到知识库的 `.obsidian/plugins/对应插件名/` 文件夹，重新打开 Obsidian。

本仓库提供的是插件设置，不包含插件程序。如果要用于已有知识库，请先备份原来的 `.obsidian` 文件夹：替换同名 JSON 文件会覆盖其中原有的设置。

## 配置内容

- 默认主题与个人强调色。
- 自动更新内部链接、附件保存位置等基础设置。
- 画布与部分内置功能的开关设置。
- 日历、动态大纲和编辑工具栏的个人设置。

更多细节请看 [使用说明](使用说明.md)。下载安装程序请访问 [Obsidian 官网](https://obsidian.md/download)。
